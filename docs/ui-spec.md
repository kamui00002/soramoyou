## 「そらもよう」特有の機能仕様

### 📸 投稿枚数制限
- **未ログインユーザー**: 1投稿あたり最大3枚
- **ログイン済みユーザー**: 1投稿あたり最大10枚

### 📷 空カメラ（撮る）
- 写真選択画面の「写真を選択」の隣に「撮る」を表示（**単一写真モードのみ**。配置写真・広角合成は複数枚前提のため非表示）
- 背面カメラが無い端末（シミュレータ含む）では非表示
- 全画面カメラにグリッド表示・水平線ガイド（水平になると色が変化）・空優先AE（白飛び防止、既定ON）を搭載。タップでフォーカス/露出、長押しでAE/AFロック
- **レンズ切替**: 端末が持つレンズを表示倍率（0.5x / 1x / 3x …）で選ぶ。ボタンのタップ・カプセル上の横ドラッグ・プレビューのピンチの3経路。ボタンは複数レンズを持つ端末にだけ出す
- **フラッシュ**: オフ / 自動 / オン（既定はオフ。空にフラッシュは届かないため）
- **記録形式**: HEIC / JPEG / RAW。RAW は **Apple ProRAW 対応端末のみ**メニューに出る（Bayer RAW は撮影時の制約が厳しくレンズ切替と両立しないため対象外）
- **解像度**: 12MP / 48MP。48MP は物理レンズを1本だけ掴んで撮るため、**レンズをまたぐ切替が一瞬もたつく**（12MP のときは従来どおりなめらか）。バッジには「いま実際に撮れる」値を出す
- 撮影した写真は写真ライブラリに自動保存後、編集画面へ遷移
- カメラ権限が拒否済みの場合はアラート表示＋「設定を開く」導線

### 🏆 いいねランキング（週間 / 月間）
- ギャラリーの並び替えチップ「新着 / 人気 / **週間 / 月間**」から表示（「人気」は全期間の累計のまま）
- **期間中に押されたいいね**（直近7日 / 直近30日のスライド窓）の数で上位30件。投稿者本人のいいねは数えない・公開投稿のみ
- 表示は通常のグリッドから専用レイアウト（`RankingListView`）に切り替わる
  - 1位: 横長（4:3）の大きなカード。2・3位: 2列のカード。どちらも写真の上にメダル（金・銀・銅）・投稿者・期間中のいいね数を重ねる
  - 4位以降: 縦リスト。左に順位の数字、サムネイル、投稿者名と副題（場所 or キャプション）、右端にいいね数
  - 同数は同順位（1, 2, 2, 4）。同順位で3位以内の投稿が4件目以降に来たら、順位の数字をメダル色にする
  - タップで詳細、長押しで「写真に保存」（通常のギャラリーと同じ操作）
- 時間帯／空の種類で絞り込み中は選べない（新着に固定）。ランキング中はシャッフルとレイアウト切替（グリッド⇔モザイク）が無効
- 集計はアプリ内（詳細は firestore-schema.md「いいねランキングのクエリ形状」）

### ⭐ 私のおすすめの空
- 自分のプロフィールに**最大3枚**の空を飾れる。**自分・他の人どちらの公開投稿も選べる**（他の人のプロフィールにも表示される）
- 追加 / 外すは投稿詳細の「…」メニュー（公開投稿のときだけ表示）。上限時は「3枚までです」と案内
- 外す・並べ替えは自分のプロフィールの欄の「編集」から。削除・非公開になった空は「整理する」で外せる
- 他の人の投稿を選ぶと、その投稿者にプッシュ通知（同じ人・同じ投稿では最初の1回だけ。リアクション通知の設定に従う）

### 📍 位置情報
- 市区町村レベルで表示
- 地図から目標物（ランドマーク）を選択可能
- CoreLocation + MapKit 使用

### 🎨 自動抽出情報
- **撮影時刻**: 元ファイルの EXIF 情報から取得（無ければ写真ライブラリの作成日時）
- **時間帯判定**: morning / afternoon / evening / night
- **空の色分析**: 主要な色を最大5色抽出（16進数カラーコード）。空マスクで**空の部分から**抽出する（被覆率 ≥0.05 かつ確信度 ≥0.3 のとき）。空を検出できない写真は**画像全体**から抽出する
- **色温度**: K（ケルビン）表示。主要色と同じく空の部分の加重平均から計算し、空を検出できない写真は画像全体の平均から計算する
