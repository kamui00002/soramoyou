### アプリ名（18 字）

```
そらもよう - 空を撮る、空を集める
```

- iOS 版と同じ名前。削除受付ページ（`/delete-account/`）のアプリ名「そらもよう」と一致する（Play は、削除のページに掲載と同じアプリ名かデベロッパー名があることを求める・13327111）
- 「空を撮る」は撮影の行為のことで、アプリ内のカメラを指さない（Android 版にカメラは無い）。気になるなら「そらもよう」だけにする

### 簡単な説明（39 字）

```
空の写真を投稿して、みんなの空を眺めよう。6種のフィルターといいねで楽しめます
```

### 2.4 コンテンツのレーティング（IARC の質問票）

手順（9859655）：連絡用のメールアドレス → カテゴリを選ぶ → 質問票 → 概要で確かめて送信。**カテゴリの一覧と質問の文はヘルプに無い**ので、画面の文を読んで、下の事実に当てはめて答える。

| 事実 | 答え | 根拠 |
|---|---|---|
| 暴力・性的な内容・下品な言葉・薬物・ギャンブル（模擬を含む）・恐怖を与える内容 | アプリ自身の内容には無い | 空の写真の投稿アプリ |
| ユーザーが作ったコンテンツを他のユーザーと共有できるか | **はい**（写真・キャプション・ハッシュタグ・表示名・自己紹介・アイコン。公開範囲「公開」は全ユーザーに見える） | 投稿・プロフィール |
| ユーザーどうしがやりとりできるか | **はい（いいねだけ）**。チャット・DM・コメントは無い | フィード・投稿詳細のいいね |
| ユーザーの位置を他のユーザーと共有するか | **いいえ**（位置の権限が無く、EXIF の位置は送る前に消す） | `docs/play-data-safety.md` §2 |
| デジタル商品の購入 | **いいえ**（課金は無い） | 同上 §2 |
| 制限のないインターネットへのアクセス（ブラウザなど） | **いいえ**（外のブラウザで開くのは、ポリシー・利用規約・削除受付ページの決め打ちの 3 つだけ。アプリ内ブラウザは無い） | `LegalLinks.kt`・`AccountDeletionViewModel.kt` |
| 不快な投稿への対策 | 通報（5 種の理由）とブロックがある。運営は通報を受けて確かめる | タスク 28〜29 |
